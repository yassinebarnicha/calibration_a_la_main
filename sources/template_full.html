Paramètres propres à chaque jour
Empile N jours consécutifs à partir du jour choisi. Le même contrat vu deux jours de suite donne deux échéances distinctes en T (T puis T − 1/365) : N jours multiplient par N les points de la structure par terme, sans nouvelle donnée à collecter. Les 11 paramètres sont partagés par tous les jours empilés — v₀ compris, ce qui ne tient que sur des jours proches.

1 · Échéances
Production = les 6 dernières échéances à plus de 10 jours, moins le 27/12/2024. Le compteur donne les options qui passent les autres filtres.
2 · Cible et filtres
Laissés vides, ces filtres s’appliquent à toutes les échéances. Un seuil les désactive sur les échéances plus courtes : à une semaine une option à 0,004 BTC est un prix d’aile normal, à un an c’est une queue illiquide dont le mark ne vaut rien.
Champ vide = pas de filtre. Spread relatif = (ask − bid) / mid ; les IV cibles sont nos propres inversions Black-76.
3 · Pricer
PROJ par défaut : N = 2¹¹, L = 20, comme pricer_proj_vec (fiable quand |μJ|, σJ ou λ sont grands). PROJ est le pricer des calibrations bi-lognormales du projet (modeles_sauts/calibrer.py). COS : N = 512, L = 24. Pas de surrogate : ceux du projet sont entraînés sur Bates.

Bi-lognormal : dF/F = √v dW + (e^Y₁ − 1) dN₁ + (e^Y₂ − 1) dN₂ − (λ₁k₁ + λ₂k₂) dt, dv = κ(θ − v) dt + σ√v dZ, Yₖ ~ N(μJₖ, σJₖ²) (modeles_sauts/modeles.py, ParamsBiLN). Le PROJ JavaScript est vérifié contre celui du projet (écart < 3e-6 $). Pipeline de données reproduit depuis data.py et calibrator5.py : règle de cible mark/mid, filtres bid > 0 et ask > 0, spread relatif < seuil, prix cible en BTC > seuil, OTM, vega Black-76 à l'IV cible, poids 1/vega² avec plancher 1e-4. Aux valeurs par défaut on retrouve exactement le carnet de production. Les RMSE IV et prix sont indépendantes de la perte choisie.

4 · Paramètres bi-lognormaux
Composante 1 = sauts fréquents et petits, composante 2 = sauts rares et grands (convention du projet, imposée par les bornes de production : λ₁ ∈ [1, 300], λ₂ ∈ [0, 1]). Avec λ₂ = 0 le modèle est exactement Bates : les calibrations Bates du jour sont proposées ainsi comme départs.
4b · Bornes des paramètreslarges
Les bornes limitent les curseurs, la saisie et l'optimiseur. κ, θ, σ, v0, σJ₁, σJ₂ doivent rester > 0 (échelle log) ; |ρ| < 1 ; λ₁, λ₂ ≥ 0. Production = bornes biln de calibrer.py. Une valeur hors des nouvelles bornes est ramenée dedans.
